# A2UI Renderer

React-приложение, реализующее нативную поддержку протокола [A2UI](https://a2ui.org) с использованием `@json-render/core`. Представляет собой чат-интерфейс для взаимодействия с A2A-агентами, которые возвращают динамический UI через протокол A2UI.

## Описание

A2UI использует модель adjacency list -- плоский список компонентов с ID-ссылками, что позволяет эффективно применять патч-обновления. Приложение отправляет текстовые сообщения A2A-серверу и отрисовывает полученные UI-компоненты в реальном времени.

### Основные возможности

- Чат-интерфейс с историей сообщений
- Рендеринг A2UI-компонентов (Text, Button, TextInput, NumberInput, DateTimeInput, Card, Row, Column, Image, Switch, Checkbox, Slider, Divider)
- Data binding -- привязка значений компонентов к модели данных
- Поддержка действий (actions) и обратных вызовов к серверу
- Сохранение истории чата и контекста в localStorage

## Быстрый старт

### Локальная разработка

```bash
npm install
npm start
```

Приложение запустится на http://localhost:3000.

### Docker

```bash
docker compose up --build
```

По умолчанию приложение будет доступно на http://localhost:3000. Чтобы изменить порт:

```bash
PORT=8080 docker compose up --build
```

Или создайте файл `.env` в корне проекта:

```
PORT=8080
```

### Прочие команды

```bash
npm run build    # Сборка для продакшена
npm test         # Запуск тестов
```

## Конфигурация

### URL сервера A2A

После запуска приложения URL сервера настраивается прямо в интерфейсе -- в шапке страницы есть поле ввода. Значение сохраняется в localStorage и переиспользуется между сессиями.

### Переменные окружения

При сборке через Docker можно переопределить порт:

| Переменная | По умолчанию | Описание |
|------------|-------------|----------|
| `PORT`     | `3000`      | Порт, на котором будет доступно приложение |

## Архитектура

```
src/
  a2ui/            # Ядро A2UI
    schemas.ts     # Zod-схемы типов сообщений A2UI
    catalog.ts     # Каталог компонентов (определения через @json-render/core)
    renderer.tsx   # React-рендерер компонентов
    useA2UI.ts     # React-хук для управления состоянием A2UI
  a2a/             # Клиент протокола A2A
    client.ts      # HTTP/SSE клиент для взаимодействия с A2A-сервером
    types.ts       # Типы A2A-протокола
    a2a-to-a2ui-adapter.ts  # Адаптер A2A -> A2UI сообщений
    message-parser.ts       # Парсер SSE-сообщений
  chat/            # UI чат-интерфейса
    ChatHistory.tsx
    ChatInput.tsx
    MessageBubble.tsx
    ServerConfig.tsx
    LoadingScreen.tsx
    storage.ts     # Работа с localStorage
    types.ts
  App.tsx          # Корневой компонент
```

### Поток сообщений

1. Пользователь вводит текст в чат
2. `A2AClient` отправляет сообщение на сервер по протоколу A2A (SSE-стриминг)
3. Сервер возвращает ответ, который может содержать A2UI-данные
4. Адаптер конвертирует A2A-ответ в `A2UIMessage`
5. Хук `useA2UI` обрабатывает сообщение и обновляет состояние:
   - `surfaceUpdate` -- добавляет/обновляет компоненты
   - `dataModelUpdate` -- обновляет модель данных
   - `beginRendering` -- устанавливает корневой компонент для отрисовки
   - `deleteSurface` -- очищает поверхность
6. `renderer.tsx` отрисовывает дерево компонентов из корневого ID

### Data Binding

Свойства компонентов могут быть:
- **Литеральными**: `{ "literalString": "Hello" }`
- **Привязанными к пути**: `{ "path": "/reservation/date" }` -- значение берется из `dataModel.reservation.date`
